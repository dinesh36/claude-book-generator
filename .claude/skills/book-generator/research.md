# Stage 1: Research

Collect sourced facts for one chapter before any writing. A chapter written from memory risks stale or wrong claims.

## Steps

1. Pick the chapter and its sections. Before an outline exists, research the whole topic once, at a high level.
2. Search for **primary sources first**: official docs, specifications, standards, papers. Add reliable secondary sources only to fill gaps.
3. Fetch and read the pages. Do not rely on search snippets.
4. Write `data/<book-name>/research/chapter-<chapter-id>.md`.

## File format

```
# Research: Chapter <N> — <title>

Researched <date>. Only claims a source supports are listed.

## Findings
1. <one claim, in your own words>. [S1]
...

## Use in the book
- Which section uses which finding.

## Gaps / not verified
- Anything you could not confirm.

## Sources
- [S1] <publisher>, <title> — <url>
```

## Rules

- Paraphrase. Do not copy long passages. Quote at most a short phrase, in quotation marks.
- Write dates in full (12 Oct 2026). Say when a fact is time-sensitive.
- If sources disagree, record both and say which you trust and why.
- Checkpoint: show the findings to the user before outlining or writing.
